# اردو سیکھے — GitHub APK Ready Project

A clean Android WebView wrapper for the Urdu learning HTML app.

## Build on GitHub
1. Upload the complete contents of this folder to a new GitHub repository.
2. Keep the folder structure exactly as provided.
3. Add the workflow from `.github/workflows/android.yml`.
4. Open **Actions → Build Android APK** and run it.
5. Download the APK from the workflow **Artifacts** section.

## Important
- Package: `com.rksolution.urdusikhe`
- App name: `اردو سیکھے`
- Portrait mode enabled.
- JavaScript + DOM storage enabled for the HTML game.
- HTML is bundled inside `app/src/main/assets/index.html`, so the app does not depend on an external website to open.
- Launcher icon is already included in drawable and density-specific mipmap folders.


## Project name
This GitHub project is named **Rekhta**. The generated debug APK is **Rekhta.apk**. The Android application ID remains `com.rksolution.urdusikhe` to avoid changing the existing app identity.
